# 远程接口型垂类模型用户指南

远程接口型垂类模型用于登记已经部署在其他服务上的预测接口。入口是“任务提交 -> 垂类预测模型 -> 垂类模型（接口配置）”，配置保存后统一进入“垂类模型管理中心”；这里也是接口模型唯一的调用入口。

## 配置流程

1. 填写模型 ID、名称、版本、开发者、开发机构、来源 URL 和引用信息。
2. 选择 `HTTP`、`FastAPI` 或 `MCP`，填写 HTTPS endpoint、HTTP 方法和 1-60 秒超时。
3. 定义输入/输出字段。POST、PUT、PATCH 默认把输入 JSON 作为 body；GET 可用 Query 绑定把输入字段映射为 URL 参数。映射只能引用已声明的输入字段。
4. 按需配置 Header 绑定、非敏感静态 Header 和密钥引用。认证 Header 和认证 Query 不允许从普通输入映射，必须使用环境变量或密钥引用，平台不会保存或返回明文凭据。
5. 配置响应提取路径，例如 `data.prediction`；留空表示使用完整 JSON 响应。样例输入必须是 JSON object。
6. 保存后执行“样例测试”。HTTP/FastAPI 测试通过后，版本进入待激活状态，再点击“激活并进入管理中心”。

接口版本不可变。修改 endpoint、协议、字段或映射时，请在模型详情中创建新接口版本；active 版本不会被覆盖。
创建待测试的新版本不会改变当前 active 版本的可用状态；重新测试 active 版本也不会把它降级为待激活状态。

## 管理与调用

模型中心按“算法上传”和“接口调用”分组筛选。接口卡片展示协议、当前 active 版本、endpoint 摘要和连通性状态，不展示完整认证 Header 或 secret 值。打开详情后，点击“立即体验”即可使用与上传算法相同的输入表单、JSON 编辑器、结果展示和运行历史。

每次调用都会记录 `AlgorithmRun`、接口协议、版本 ID、上游主机摘要、HTTP 状态码和耗时。请求头、token、原始敏感响应和内部网络细节不会写入运行记录或返回前端。

## 协议边界和错误

- HTTP/FastAPI 首期按同步 HTTP 调用执行，不自动重试，也不跟随重定向。
- MCP 当前只支持配置和展示；测试、激活和调用返回 `REMOTE_PROTOCOL_NOT_SUPPORTED`（HTTP 501），不会伪装成可用能力。
- 配置错误返回 422；权限不足返回 403。样例测试会返回结构化的 `ok=false`、错误码和错误信息；正式运行时，上游非 2xx、非法 JSON、响应路径缺失或输出契约不匹配返回 502，超时返回 504。
- 生产环境要求 HTTPS，并默认阻断 loopback、私网、link-local 和保留地址。开发环境只有显式允许时才能访问私网地址。
- 上游响应受平台大小限制，避免把大响应直接带入运行记录。

## 来源标注

开发者、开发机构、来源 URL 和引用会在卡片、详情和调用结果附近以结构化来源牌展示。未提供授权 Logo 时使用文字来源牌，不生成或冒用机构 Logo；平台的治理和调用能力不归属远程模型开发者。
