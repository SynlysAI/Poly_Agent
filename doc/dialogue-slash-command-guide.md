# `/dialogue` Slash Command 与统一回放指南

`/dialogue` 的 Slash Command 是用户控制面，不进入模型请求历史。命令结果、权限决策、模型执行、算法工具、上下文压缩、导出与反馈都会写入同一条会话事件流，并可在“会话统一回放”面板中按类型查看。

## 基本操作

1. 在输入框行首输入 `/` 打开命令面板。
2. 继续输入可按前缀和模糊匹配过滤；支持鼠标点击、`↑` / `↓`、`Enter` 与 `Esc`。
3. 需要参数的命令会在结果卡中返回选项或表单；确认类命令必须二次确认。
4. 面板中的动态算法命令继续展示算法来源、开发者与确认要求。

## 内置命令

| 命令 | 作用 | 审计与边界 |
|---|---|---|
| `/plan [off|<任务说明>]` | 开启、退出 Plan Mode，或在开启后创建计划任务 | Plan Mode 不是 OS 沙箱；工具确认阶段由后端阻断执行 |
| `/goal [clear|<目标>]` | 查看、设置或清除长期目标 | 事件仅保存目标摘要，不把目标正文复制进命令事件 |
| `/permission [read-only|workspace-write|full-access]` | 切换会话工具执行边界 | 只叠加当前 LUI 控制面约束，不替代平台 RBAC 与工具策略 |
| `/model [<provider_id>::<model_id>]` | 查看或切换当前会话模型 | Goal、Todo、Trace、权限与工具选择不因模型切换丢失 |
| `/status` | 查看模型、模式、目标、权限、活动 run 与工具调用 | 只读汇总，不创建模型 run |
| `/reset [confirm|cancel]` | 确认后重置 Plan、权限、目标与 Todo | 不删除消息、run、工具调用、导出记录与事件 |
| `/clear` | 创建并切换到新会话 | 旧会话仍保留在历史列表，可继续回放 |
| `/compact` | 压缩已完成历史，保留目标、任务、权限、结论与活跃工具结果 | 原始消息保留，后续请求使用服务端快照 |
| `/export [json|markdown|zip]` | 导出会话、命令、Trace、工具与 artifact 索引 | 下载走 owner 校验；缺失 artifact 只记录 manifest 错误 |
| `/feedback` | 对实际模型执行提交有帮助 / 需改进反馈 | 正文仅保存在反馈权威记录，不进入命令事件 |

当前用户可用的已部署算法会自动派生为动态命令。选择后进入既有参数表单、附件、确认与 AlgorithmRun 执行链路；结果继续展示算法开发者、方法来源和授权机构 Logo。

动态算法命令的可用状态与会话控制面同步：`/permission read-only` 或 `/plan` 开启后，命令面板会把工具命令标记为不可用并展示原因；退出 Plan Mode、恢复可执行权限或执行 `/reset` 后自动刷新目录。

## 会话统一回放

“会话统一回放”面板复用 Plan 09 的 append-only Execution Trace 投影，合并以下事件：

- Slash Command 生命周期
- 模型 run 生命周期
- 算法工具调用与结果
- 权限决策与 Plan Mode 阻断
- Goal / Todo /权限模式变化
- 上下文压缩
- 导出
- 反馈

面板支持“全部 / 命令 / 控制 / 模型 / 工具 / 导出 / 反馈”过滤，并使用连续 `after_seq` 游标做断线后的增量恢复。展开单个步骤可查看脱敏后的安全详情与原始事件引用；界面不展示完整 prompt、Chain of Thought、API key 或未脱敏文件内容。

## 来源说明

Slash Command 与会话控制面参考 DeepSeek Harness 的命令注册、输入触发、Plan Mode、权限预设、压缩、导出与反馈交互架构；对话工作台与工具调用交互参考 Open WebUI。PolyAgent 未复制上述项目代码，实际命令平面、双模事件存储、统一 Trace 投影、权限门禁、前端时间线和算法集成均为本项目实现。外部参考在页面中仅使用文字来源牌；算法来源以算法包登记的开发者、机构、引用和授权 Logo 为准。
