# 实验设计与优化工具 — 操作流程

## 一句话概述

用尽量少的实验次数，帮你找到性能最好的实验条件。基于贝叶斯优化（主动学习），边做实验、边建模型、边让模型推荐最值得做的下一批实验。

## 适用场景

- 实验成本高、周期长
- 变量多，不知道最优条件在哪里
- 想减少试错次数，让实验设计更系统化

---

## 整体流程

```
变量定义 → 实验设计 → 实验数据 → GP 建模 → 采集优化 → 可视化诊断
                                      ↑                        │
                                      └──── 循环迭代 ──────────┘
```

共 6 个步骤，下面逐一说明。

---

## 步骤 1：变量定义

**目的**：告诉系统你能调哪些实验条件，定义"搜索空间"。

| 变量类型 | 说明 | 示例 |
|---------|------|------|
| 连续实值 | 在上下限范围内连续取值 | 温度 300-500 °C |
| 整数 | 在上下限范围内取整数值 | 批次数 1-10 |
| 分类 | 从预设类别中选择 | 催化剂类型 A/B/C |
| 离散值 | 从特定数值列表中选择 | 硅铝比 80 或 280 |

每个变量可填写**单位**和**描述**，方便后续理解。

**操作**：点击"添加变量"→ 填写名称/类型/范围 → 保存。可编辑、删除已添加的变量。

---

## 步骤 2：实验设计

**目的**：在没有任何实验数据的情况下，生成一批合理的初始实验点，覆盖搜索空间。

### 2.1 初始设计（DoE — 实验设计）

提供 11 种设计方法，分为三组：

**空间填充方法**（需指定实验点数量）：
| 方法 | 特点 | 专属参数 |
|------|------|---------|
| 拉丁超立方 (LHS) | 最常用，均匀覆盖各维度 | 准则（Maximin/Correlation/Ratio）、随机种子 |
| 随机采样 | 简单，无先验知识时可用 | 随机种子 |
| Sobol 序列 | 低差异序列，比随机更均匀 | 随机种子 |
| Halton 序列 | 确定性准随机序列 | 随机种子 |
| Hammersly 序列 | 同 Halton，计算简单 | 随机种子 |

**经典 RSM 方法**（实验次数由设计结构自动决定）：
| 方法 | 特点 | 专属参数 |
|------|------|---------|
| 全因子设计 | 覆盖所有因子水平组合，实验量大 | 每因子水平数（2-3）、中心点重复 |
| 部分因子设计 | 2 水平筛选，大幅减少实验量 | 生成器字符串、中心点重复 |
| 中心复合设计 (CCD) | 经典响应面方法 | Alpha 类型、面类型、中心点重复 |
| Box-Behnken 设计 | 响应面方法，避免极端组合 | 中心点重复 |

**筛选方法**：
| 方法 | 特点 | 专属参数 |
|------|------|---------|
| Plackett-Burman | 超高效 2 水平筛选 | — |
| 广义子集设计 (GSD) | 支持混合变量类型 | 每因子水平数（2-5）、缩减因子 |

> 注意：CCD、Box-Behnken、部分因子设计、Plackett-Burman 不支持分类变量。含分类变量时请用 GSD、LHS 或全因子设计。

生成设计矩阵后，可在表格中填写**输出值 Output**（必填）和**噪声 Noise**（可选），然后点击"添加为实验数据"。

**LLM 建议**：点击"LLM 建议"按钮，AI 会根据当前变量和已有实验数据推荐实验条件组合。

### 2.2 最优设计（OED — 最优实验设计）

当对实验系统有一定了解，知道关注哪些效应时使用。统计意义上最优的设计方案。

**模型规格**：
- **线性 (Linear)**：仅主效应，适合初步筛选
- **交互 (Interaction)**：主效应 + 两两交互项
- **二次 (Quadratic)**：主效应 + 交互 + 平方项，适合响应面建模
- **自定义**：手动勾选需要的主效应、交互项、二次项

**LLM 辅助效应建议**：在自定义模式下，可描述实验系统让 AI 建议哪些效应项可能是重要的，支持一键应用到复选框。

**设计参数**：
| 参数 | 说明 |
|------|------|
| 最优性准则 | D-optimal（参数估计）/ A-optimal（最小化方差）/ I-optimal（预测方差） |
| 交换算法 | Fedorov（推荐）/ Modified Fedorov / DetMax / Simple Exchange / Sequential |
| 实验次数 | p × 倍数（按模型列数自动计算）或固定数量 |

**操作流程**：
1. 选择模型规格
2. 点击"预览模型项"确认模型项列表和推荐实验数
3. 调整设计参数
4. 点击"生成最优设计"
5. 查看设计质量指标（D-效率、A-效率）
6. 暂存到实验队列 或 导出 CSV

---

## 步骤 3：实验数据

**目的**：管理所有带输出值的真实实验数据，这是建模的基础。

### 3.1 导入数据（三种方式）

| 方式 | 说明 |
|------|------|
| 实验设计页面填写 | 在步骤 2 中生成设计矩阵 → 填写 Output → "添加为实验数据" |
| 手动新增 | 点击"新增实验数据"→ 逐条填写变量值、Output、Noise、Iteration、Reason |
| **CSV 导入** | 点击"导入 CSV"→ 选择 CSV 文件 → 预览列结构 → 确认导入 |

**CSV 格式要求**：列名需与变量名称匹配，需包含目标列（默认 "Output"），可选的 "Noise" 列。若 CSV 中无 "Output" 列，导入时可选择其他列作为目标值。

### 3.2 统计摘要

页面顶部展示：实验数量、Output 最小值/最大值/均值，帮助快速了解数据概况。

> **重要**：只有带 Output 的数据才是可用于建模的真实实验数据。GP 建模至少需要 5 条。

---

## 步骤 4：GP 建模

**目的**：用已有实验数据训练高斯过程（GP）代理模型，学习变量与结果之间的关系。

| 配置项 | 选项 | 说明 |
|--------|------|------|
| 核函数 | Matern 5/2、Matern 3/2、RBF、IBNN | 决定模型平滑度和灵活性 |
| 计算后端 | scikit-learn（基础稳定）、BoTorch（功能更强） | IBNN 核函数需 BoTorch |
| ARD | 开/关 | 自动相关性确定，每个变量独立长度尺度 |

**操作**：选好核函数和后端 → 点击"训练模型" → 查看 R²、RMSE、MAE 等评估指标。

---

## 步骤 5：采集优化

**目的**：模型建好后，推荐下一批最值得做的实验，平衡"利用"（去预测值最好的地方）和"探索"（去不确定性最大的地方）。

### 5.1 采集策略

| 策略 | 类型 | 说明 |
|------|------|------|
| EI | 单点 | 期望改进，最常用 |
| PI | 单点 | 改进概率 |
| UCB | 单点 | 上置信界，可调 kappa |
| qEI | 批量 | 并行期望改进，推荐多个点 |
| qUCB | 批量 | 并行 UCB |
| qNIPV | 探索 | 纯探索，不优化目标值 |

**参数**：
- **优化目标**：最大化 / 最小化
- **xi**（EI/PI）：探索权重，越大越偏向探索
- **kappa/beta**（UCB/qUCB）：置信界宽度

### 5.2 寻找最优点

点击"寻找最优点"直接搜索模型预测值最优的实验条件。注意：纯利用，不考虑探索，建议在模型精度足够时使用。

### 5.3 闭环迭代

```
采集优化推荐实验 → 做完实验 → 填入 Output → 重新训练模型 → 再次推荐
```

如此反复，逐步逼近最优条件。

---

## 步骤 6：可视化诊断

**目的**：判断模型可信度和理解优化效果。

| 图表类型 | 作用 |
|---------|------|
| Parity 图 | 实际值 vs 预测值散点图，含误差棒和多 sigma 置信区间 |
| CV 指标曲线 | RMSE/MAE/MAPE/R² 随训练量变化趋势 |
| Q-Q 图 | 残差正态性诊断，含 95% 置信区间 |
| 校准曲线 | 置信度-覆盖率检验，验证模型不确定性估计是否可靠 |
| 等值线图 | 2D 变量空间预测值热力图，可叠加实验点和建议点 |
| 超参数展示 | 核函数长度尺度等超参数 |

> 可视化不是必须步骤，但对判断"模型是否可信"、"下一轮该往哪个方向探索"非常重要。

---

## Session 管理

Session 是整个优化过程的持久化单元，包含变量定义、实验数据、模型结果等全部信息。

| 操作 | 说明 |
|------|------|
| 新建 Session | 创建一个新的优化项目 |
| Session 选择器 | 下拉切换不同的优化项目 |
| 导入 | 从 JSON 文件恢复之前的 Session |
| 导出 | 将当前 Session 保存为 JSON 文件 |

---

## LLM 配置

点击顶栏的"LLM 配置"按钮，设置：
- **API 地址**：OpenAI 兼容接口地址（Ollama 填写 `http://localhost:11434/v1`）
- **API Key**：密钥
- **模型名称**：如 `gpt-4o`、`llama3` 等

配置后可在实验设计步骤中使用 LLM 辅助建议。
